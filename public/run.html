01

Clone, install and start

Use Node.js 24 or newer. The committed lockfile fixes this project's dependencies. Starting the host makes no provider call.

Run the completed application

git clone https://github.com/luiscoco/Udemy-Mastra-lesson10-app.git
cd Udemy-Mastra-lesson10-app
npm ci
npm start

Open http://127.0.0.1:3210. Choose Run practical lab first. Keep the terminal open; Ctrl+C stops the host.

02

Try the cases and inspect evidence

  • Retry a transient pre-output failure: Two application attempts, one bounded retry and a complete fixture stream.
  • Fail after partial output: Partial text remains visible and is not automatically replayed.
  • Test Stop while streaming: Use Stop during delivery; cancellation must not trigger a retry.

The cases are editable classroom inputs, not fabricated model responses. Local outcomes come from executing the actual implementation.

03

Configure the optional live agent

PowerShell: preserve an existing local configuration

if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env

Enter your own provider key locally, then restart with npm start

OPENAI_API_KEY=your_api_key
MASTRA_MODEL=openai/gpt-4.1-mini
PORT=3210

Use a model your provider account can access. Credentials stay on the server and are ignored by Git. Existing shell values take precedence over the optional file. No credential is copied from lesson 1 or another application.

Bash alternative

Bash: local environment setup

[ -f .env ] || cp .env.example .env
# Edit .env with your own values.
npm start

Terminal examples and checks

The normal sample and offline tests need no provider key

npm run sample
npm run sample:live
npm run build
npm test
npm run test:browser

The live sample is a real provider request. Browser checks use an installed Chrome/Chromium executable; set BROWSER_EXECUTABLE if it is not in the standard location. Tests use explicit SDK fixtures for model integration, not paid API calls.

Rebuild after source changes. The five pages, their source line references and the browser bundle are generated from this project's actual files.

Troubleshooting boundaries

FindingNext check
Invalid JSON or schemaRepair the submitted input before changing models or credentials.
Needs attentionRead the business result and validation details; SDK execution alone may have succeeded.
Live key not configuredSet the selected provider's key locally and restart. The practical operation remains available.
Provider failureCheck account access, model identity, supported options and network access. Raw provider exceptions are not displayed.
Port in useStop your existing host or choose a different PORT. Follow the printed URL.
Partial text after StopCancellation is distinct from completion. Partial text is retained as incomplete evidence.
