Streaming Error Handling and Retries

Application labWhat you will learnHow to runArchitecture & workflowCode walkthrough
01

Append delivery chunks correctly

Chunks are delivery units, not guaranteed words or Markdown blocks. The browser accumulates text and renders the current safe Markdown view.

02

Distinguish run states

Idle, running, completed, failed and cancelled are separate states. Receiving some text does not justify reporting success.

03

Retry only appropriate failures

The application retries selected transient statuses before visible output, within a two-attempt budget. Permanent input errors are not retried.

04

Preserve partial output

Once text has been emitted, an automatic restart can duplicate or contradict it. The lab exposes the partial text and the failure outcome.

05

Propagate cancellation

Stop aborts the browser request and the server's work. Abort during delivery or backoff is not treated as a transient provider failure.

06

Inspect actual evidence

Attempt counts and retry events come from executed code. Local fault injection is clearly labelled; live mode uses Agent.stream and its final output.

Check your understanding

Is one received chunk proof of success?

No. Completion depends on a final successful outcome. A transport or provider failure can occur after partial text.

Should cancellation retry automatically?

No. It is an intentional stop signal, including during retry backoff.

Are the local fixture chunks actual model output?

No. They are explicitly labelled deterministic transport fixtures. The separately configured live action uses a real Mastra stream.

Implemented scope: The local lab uses controlled fixture text and injected errors to exercise real HTTP delivery. Live mode invokes Mastra Agent.stream. The application does not claim invented provider performance or hidden reasoning.

Practical exercise

Compare transient-before-text with partial-failure, then cancel during delivery. Use the observed attempt count and final state to explain when retrying is appropriate.
